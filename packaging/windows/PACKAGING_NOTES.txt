Source Document Converter - unsigned development build

This folder is not a production release. Keep the folder contents together.

Executables:
- SourceDocumentConverter.exe starts the desktop application.
- docling-tools.exe is the companion used only for explicit model setup.

OCRmyPDF, Tesseract OCR, and Ghostscript are external dependencies in this package.
Use Help > System Check > Install Missing OCR Tools to run guided winget setup when available,
or configure validated executable paths manually.

Models are not included. Choose a model folder and approve the download through Help > System Check.
Document conversion does not automatically download models.

Verify generated Markdown and JSON against the original PDF before relying on them.
The original PDF remains authoritative.
